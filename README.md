## GitHub Pages Deployment Checklist
1. Create or open your repository on GitHub.
2. Upload these 15 HTML files and your 15 couple photos (`*.JPG`) & 15 backgrounds (`*.jfif`).
3. Add an empty file named `.nojekyll` to the repository root so GitHub Pages doesn't ignore files starting with underscores.
4. In GitHub Settings -> Pages, select branch 'main' and root '/ (root)'.
5. Access your calendar months at:
   https://<username>.github.io/<repo>/October_2026.html
